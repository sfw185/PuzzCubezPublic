# PuzzCubezPublic

The website for PuzzCubez, a puzzle game for iOS and Android, at [puzzcubez.australian.software](https://puzzcubez.australian.software): its home, support and privacy pages. Everything in `site/` is published by GitHub Pages whenever `main` changes, and Cloudflare serves the domain. The game itself is in a private repository.

The home page says "Coming soon" until Apple's lookup service finds the app in the US or Australian store, then shows the App Store badge, linking to https://apps.apple.com/app/id6826485437, by itself. Beside it, "Coming soon to Google Play" stands in until the Android app (`com.wardan.puzzcubez`) is listed, when it should become Google's badge linking to https://play.google.com/store/apps/details?id=com.wardan.puzzcubez.
